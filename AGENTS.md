# Project objective

This site's audience is YC people, startup founders/operators, and anyone
who could open a door to Silicon Valley. Every content and feature
decision should be made through that lens: what makes this read as
credible and worth a reply to that specific audience, not a generic
portfolio. When proposing or building features, prioritize the ones that
help this objective (visible signal of shipped work, open-source
contributions, live GitHub activity, a clear way to get in touch) over
generic portfolio polish.
